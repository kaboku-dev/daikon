description: Draft a pull request description for the current branch
---

Write a PR description for the current branch against `main`, based on `git log` and `git diff` for the branch.

Do not create the PR; output the text only, in English.

Start with a title: imperative, concise (up to about 72 characters). It will likely become the squash commit message on `main`.

Then include: what changed, why, how it was tested, and anything relevant. Keep it brief.
